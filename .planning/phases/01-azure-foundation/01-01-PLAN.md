# Plan 01-01: Foundation and Networking

## Objective
Establish the root Terraform module with the local state backend, create the foundational `networking` module (VNet, subnets, and NSGs), and configure the Azure budget alert.

## Must Haves
- The root module must define the Azure provider and local state backend.
- The `networking` module must create a VNet (`10.0.0.0/16`) and 4 subnets: `system-subnet` (10.0.1.0/24), `user-subnet` (10.0.2.0/24), `infra-subnet` (10.0.4.0/24), and `ingress-subnet` (10.0.5.0/24).
- A budget alert must be created in the root module for the resource group with 80% and 100% thresholds based on a $25 monthly budget.
- All created resources must include the standard tags: `environment = "homelab"`, `managed-by = "terraform"`.
- NSGs must be applied to all subnets with basic egress rules allowing Internet access (HTTP/HTTPS/NTP) but denying other untrusted egress, while allowing intra-VNet communication.

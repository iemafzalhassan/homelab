# Plan 02-01: AKS Terraform Module

## Context
Deploy the AKS Cluster acting as our control plane and system node pool.
The cluster will have Azure CNI Overlay, OIDC Issuer, and Workload Identity enabled, as required for future phases.

## Steps

1. **Create `modules/aks/variables.tf`**:
   - `resource_group_name`, `location`
   - `vnet_id`, `system_subnet_id`
   - `admin_ip_range` (for API server restriction)

2. **Create `modules/aks/main.tf`**:
   - `azurerm_kubernetes_cluster` resource:
     - `name`, `location`, `resource_group_name`, `dns_prefix`
     - `kubernetes_version` = "1.35"
     - `oidc_issuer_enabled = true`
     - `workload_identity_enabled = true`
     - `network_profile`:
       - `network_plugin = "azure"`
       - `network_plugin_mode = "overlay"`
       - `pod_cidr = "10.244.0.0/16"`
     - `default_node_pool`:
       - `name = "system"`
       - `vm_size = "Standard_D2as_v5"`
       - `vnet_subnet_id = var.system_subnet_id`
       - `zones = ["1"]`
       - `node_count = 1`
       - `os_disk_type = "Managed"`
       - `os_disk_size_gb = 30`
     - `identity { type = "SystemAssigned" }`
     - `api_server_access_profile`:
       - `authorized_ip_ranges = [var.admin_ip_range]`

3. **Create `modules/aks/outputs.tf`**:
   - `cluster_name`
   - `kube_config_raw` (sensitive)
   - `oidc_issuer_url`

4. **Update `main.tf`**:
   - Call the `aks` module, passing the variables.

5. **Update `variables.tf` & `outputs.tf` (Root)**:
   - Add `admin_ip_range` to `variables.tf`.
   - Add `kube_config_raw` and `oidc_issuer_url` to `outputs.tf`.

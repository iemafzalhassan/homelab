# Plan 02-02: Kubeconfig and Makefile

## Context
After the AKS cluster is provisioned, we need an easy way to interact with it via `kubectl`. We also need to restrict the API server to the administrator's IP address. Since homelab IPs often change, we'll create a `make` target to update the authorized IP dynamically.

## Steps

1. **Create `Makefile` in the root**:
   - Add target `get-credentials`:
     - Uses `az aks get-credentials --resource-group homelab-rg --name homelab-aks --overwrite-existing`.
   - Add target `update-ip`:
     - Fetches current public IP using `curl -s ifconfig.me`.
     - Uses `az aks update --resource-group homelab-rg --name homelab-aks --api-server-authorized-ip-ranges <IP>/32`.

2. **Update `terraform.tfvars.example`**:
   - Add `admin_ip_range = "YOUR_IP_ADDRESS/32"`.

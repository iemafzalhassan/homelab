# Phase 7: CI/CD (Jenkins on Spot Nodes)

This plan covers provisioning the Azure Spot Node Pool, Azure Container Registry (ACR), and deploying Jenkins via ArgoCD. Jenkins will be configured via JCasC to dynamically spin up ephemeral build agents on the spot nodes, utilizing Kaniko for rootless Docker image builds and Workload Identity to push to ACR securely.

> [!IMPORTANT]
> **User Review Required**
> 1. **ACR Pricing**: I will provision an Azure Container Registry (ACR) using the `Basic` SKU to minimize cost (~$5/month). Is this acceptable within our $100 budget?
> 2. **Jenkins Persistent Storage**: Jenkins controller will use a small 8Gi PVC. Let me know if you prefer a fully stateless deployment (which implies losing build history on pod restart).

### Kubernetes Manifests (Jenkins & ArgoCD)

#### [NEW] `manifests/apps/jenkins.yaml`
- ArgoCD Application defining the Jenkins deployment, pointing to the official `jenkins/jenkins` Helm chart.

#### [NEW] `manifests/bootstrap/jenkins/values.yaml`
- Configure the Jenkins Controller:
  - `serviceAccount.annotations`: Add the Workload Identity Client ID.
  - PVC for persistence (8Gi).
  - JCasC (Configuration as Code) setup.
- Configure JCasC for the Kubernetes Cloud plugin:
  - Add a Pod Template for Kaniko (rootless image builds).
  - Add Node selector and Toleration for `kubernetes.azure.com/scalesetpriority=spot:NoSchedule` so agents run *only* on the spot pool.
- Define a single sample Pipeline Job in JCasC that clones the homelab repo and runs the `Jenkinsfile`.

#### [NEW] `Jenkinsfile` (Root directory)
- A sample Jenkins pipeline that:
  1. Uses the Kaniko agent container.
  2. Authenticates to ACR via Azure Workload Identity.
  3. Builds a dummy `Dockerfile` and pushes to the ACR.

## Verification Plan

### Automated Tests
- `terraform plan` to verify spot node and ACR creation.
- `kubectl get pods -n jenkins` to ensure the controller starts successfully.

### Manual Verification
1. Open `https://jenkins.smapatticare.com` and verify the UI loads over HTTPS.
2. Trigger the sample pipeline job manually.
3. Observe a new spot node being provisioned (via `kubectl get nodes`) and the Jenkins agent pod spinning up.
4. Verify the Kaniko build succeeds and the image appears in the Azure Container Registry.
5. Verify the agent pod is deleted and the spot node eventually scales back to 0.
